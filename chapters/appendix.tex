\section{Общие положения}

Настоящий документ содержит перечень функциональных и нефункциональных требований к государственной информационной системе каталогизации и управления цифровыми активами граждан Российской Федерации в контексте наследственных правоотношений (далее --- Система).

Требования сформированы на основе анализа предметной области, правового регулирования, участников процесса, а также моделирования целевого процесса управления цифровыми активами граждан.

Структура требований разработана с учётом положений ГОСТ 34.602-89 и ГОСТ Р ИСО/МЭК/IEEE 29148-2017.

\section{Назначение и цели системы}

\subsection{Назначение системы}

Система предназначена для:
\begin{itemize}
    \item прижизненной каталогизации цифровых активов граждан;
    \item фиксации волеизъявления гражданина в отношении цифровых активов;
    \item обеспечения контролируемого доступа к сведениям об активах в рамках наследственной процедуры;
    \item информационной поддержки нотариальной деятельности и межведомственного взаимодействия.
\end{itemize}

\subsection{Цели создания системы}

Основными целями создания Системы являются:
\begin{itemize}
    \item снижение рисков утраты активов и нарушения воли владельца;
    \item повышение прозрачности и эффективности наследственных процедур;
    \item обеспечение юридически значимого хранения информации об цифровых активах, пренадлежащих гражданам.
\end{itemize}

\section{Объект автоматизации}

Объектом автоматизации являются процессы:
\begin{itemize}
    \item учёта и структурирования сведений о цифровых активах;
    \item Храненя доступа к некоторым типам активов;
    \item фиксации распоряжений владельца;
    \item управления доступом к информации об активах;
    \item взаимодействия участников наследственной процедуры.
\end{itemize}

\section{Участники системы}

Ключевыми участниками системы являются:
\begin{itemize}
    \item гражданин (владелец активов);
    \item наследник;
    \item доверенное лицо;
    \item нотариус;
    \item оператор системы;
    \item внешние поставщики цифровых услуг;
    \item государственные информационные системы.
\end{itemize}

\section{Функциональные требования}

\subsection{Общие требования}

Система должна обеспечивать выполнение функций учёта, управления и предоставления сведений о цифровых активах в соответствии с установленными правами доступа.

\subsection{Регистрация и идентификация пользователей}

\begin{itemize}
    \item FR-01 Система должна обеспечивать регистрацию пользователей с использованием государственных систем идентификации (например, ЕСИА).
    \item FR-02 Система должна обеспечивать аутентификацию пользователей.
    \item FR-03 Система должна поддерживать многофакторную аутентификацию для критических операций.
\end{itemize}

\subsection{Управление цифровыми активами}

\begin{itemize}
    \item FR-04 Система должна обеспечивать создание карточек цифровых активов.
    \item FR-05 Система должна обеспечивать классификацию активов по типам.
    \item FR-06 Система должна поддерживать редактирование и актуализацию сведений об активах.
    \item FR-07 Система должна обеспечивать хранение атрибутов активов и связанных документов.
\end{itemize}

\subsection{Управление распоряжениями}

\begin{itemize}
    \item FR-08 Система должна обеспечивать фиксацию волеизъявления гражданина.
    \item FR-09 Система должна поддерживать назначение наследников и доверенных лиц.
    \item FR-10 Система должна обеспечивать настройку условий доступа к активам.
\end{itemize}

\subsection{Управление доступом}

\begin{itemize}
    \item FR-11 Система должна обеспечивать разграничение доступа на основе ролей.
    \item FR-12 Система должна учитывать правовые основания доступа.
    \item FR-13 Система должна поддерживать принцип минимально необходимого доступа.
\end{itemize}

\subsection{Исполнение наследственного сценария}

\begin{itemize}
    \item FR-14 Система должна обрабатывать события, связанные с наступлением юридически значимого факта.
    \item FR-15 Система должна обеспечивать передачу допустимого объёма сведений уполномоченным лицам.
    \item FR-16 Система должна обеспечивать обработку сценариев отсутствия наследников.
\end{itemize}

\subsection{Межсистемное взаимодействие}

\begin{itemize}
    \item FR-17 Система должна обеспечивать интеграцию с государственными реестрами.
    \item FR-18 Система должна обеспечивать взаимодействие с нотариальной инфраструктурой.
    \item FR-19 Система должна поддерживать обмен данными с внешними сервисами.
\end{itemize}

\subsection{Журналирование и аудит}

\begin{itemize}
    \item FR-20 Система должна фиксировать все юридически значимые действия.
    \item FR-21 Система должна обеспечивать хранение журналов событий.
    \item FR-22 Система должна обеспечивать возможность аудита действий пользователей.
\end{itemize}

\section{Нефункциональные требования}

\subsection{Требования к безопасности}

\begin{itemize}
    \item NFR-01 Система должна обеспечивать защиту от несанкционированного доступа.
    \item NFR-02 Система должна обеспечивать шифрование данных.
    \item NFR-03 Система должна обеспечивать контроль целостности информации.
\end{itemize}

\subsection{Требования к надёжности}

\begin{itemize}
    \item NFR-04 Система должна обеспечивать отказоустойчивость.
    \item NFR-05 Система должна обеспечивать резервное копирование данных.
\end{itemize}

\subsection{Требования к производительности}

\begin{itemize}
    \item NFR-06 Время отклика системы не должно превышать установленного значения.
    \item NFR-07 Система должна поддерживать одновременную работу заданного количества пользователей.
\end{itemize}

\subsection{Требования к удобству использования}

\begin{itemize}
    \item NFR-08 Интерфейс системы должен быть интуитивно понятным.
    \item NFR-09 Система должна соответствовать требованиям цифровой доступности.
\end{itemize}

\subsection{Требования к масштабируемости}

\begin{itemize}
    \item NFR-10 Система должна обеспечивать возможность расширения функциональности.
\end{itemize}

\subsection{Требования к хранению данных}

\begin{itemize}
    \item NFR-11 Система должна обеспечивать долговременное хранение данных.
    \item NFR-12 Система должна обеспечивать неизменяемость архивных данных.
\end{itemize}

\section{Требования к информационному обеспечению}

\begin{itemize}
    \item Система должна обеспечивать хранение структурированных данных об активах.
    \item Система должна обеспечивать ведение справочников и классификаторов.
\end{itemize}

\section{Требования к защите информации}

\begin{itemize}
    \item Система должна соответствовать требованиям законодательства о персональных данных.
    \item Система должна обеспечивать разграничение доступа к конфиденциальной информации.
\end{itemize}

\section{Требования к сопровождению и эксплуатации}

\begin{itemize}
    \item Система должна обеспечивать мониторинг состояния.
    \item Система должна поддерживать обновление без остановки работы.
\end{itemize}
